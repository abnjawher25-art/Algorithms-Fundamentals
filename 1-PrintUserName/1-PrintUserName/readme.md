# 🔤 Name Printer Project

A mini-project demonstrating how to define and use **functions** in **C++** to pass and print string arguments, built as part of fundamental algorithm and structured programming practices.

---

## 🎯 Learning Objectives

* 🔹 Understanding how to define and format **void functions**.
* 🔹 Passing `string` parameters into functions.
* 🔹 Organizing code structure by separating helper functions from the `main()` entry point.

---

## 💻 Source Code

```cpp
#include <iostream>
using namespace std;

// Function to print the name
void printedName(string name)
{
    cout << "the name: " << name;
}

// Main function
int main()
{
    printedName("Ebrahim");

    // Complete execution
    return 0;
}

```

---

## 🖥 Expected Output

```text
the name: Ebrahim

```
